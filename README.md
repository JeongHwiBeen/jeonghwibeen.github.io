# 정휘빈 개발자 포트폴리오

https://jeonghwibeen.github.io/

Node.js 20 이상에서 npm run dev로 로컬 서버를 시작합니다. npm run build로 dist를 생성하고 npm test로 링크를 점검합니다.

content/projects에 기존 형식의 JSON을 추가하면 프로젝트가 등록됩니다. 프로필·경력·교육·연락처는 content/profile.json에서 수정합니다. 공개 전에 개인 정보와 회사 정보의 공개 범위를 확인합니다. main 변경 시 GitHub Actions가 정적 파일을 빌드·검증하고 GitHub Pages로 배포합니다.
